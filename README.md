🇬🇧 English Description
🧩 About

Wolfscatt.dev is a personal portfolio and project hub created by Ömer Faruk BİNGÖL, a software engineer who values architecture over mere coding.
The site combines modern technology with historical aesthetics, showcasing works that range from mobile apps to AI-driven systems.

🧠 Features

📱 Store-like Layout:
Projects are categorized just like a mini Google Play Store — Mobile, Games, Desktop, Web, AI & Machine Learning.

🧩 Project Detail Pages:
Each project includes images, descriptions, GitHub links, and optional download buttons (APK/EXE).

🤖 AI & ML Projects:
Includes works on Machine Learning, Deep Learning, and RAG-based NLP systems.

💬 Contact Form:
Visitors can send messages directly through a database-backed contact form.

⚙️ Supabase Integration:
Contact messages and project data are stored dynamically in Supabase.

🌌 Design Concept:
A fusion of dark, futuristic aesthetics with subtle historical (Göktürk-inspired) visual touches.
